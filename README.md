# Chapo Sports Bar Website

Static responsive website package for GitHub Pages or Vercel.

## Included
- Black + gold Chapo branding
- Opening Soon hero
- 21+ age gate
- Experience, VIP/private events, gallery, location and contact sections
- Google Maps embed and directions link
- Instagram and Facebook links
- Event/VIP inquiry form
- Mobile navigation and image lightbox
- All supplied images renamed to simple web-safe filenames

## Deploy
Upload the entire folder contents to a GitHub repository. For Vercel, import the repository and deploy as a static site. No build command is required.

## Form note
The included inquiry form works without a backend by opening the visitor's email app with a pre-filled email to `chapossportsbar@gmail.com`. Before production launch, it can be connected to Formspree, Web3Forms, Resend, or another form endpoint so submissions happen directly on the site.

## Before launch
Confirm the official opening date, operating hours, menu, VIP policies, pricing, and final event capacity with the business. Replace the "Opening Soon" copy when those details are official.
